# ¡Albricias!

Self-serve, stateless GitHub-activity newspaper generator. See the
repo-root `README.md` for the product overview.

## Setup

```bash
npm run setup   # installs deps, creates .env if missing
npm run dev
```

Set `GITHUB_TOKEN` in `.env` — a personal access token with no special
scopes, used server-side for every visitor's read-only activity lookup
(visitors only ever supply a GitHub *username*, never a token). Without it,
GitHub's unauthenticated rate limits (10 req/min on the search API) are
exhausted almost immediately.

Open [http://localhost:3000](http://localhost:3000): `/` is the landing
page, `/app` is the generator. There is no login and nothing is saved —
every "Print My Edition" is one request from form submission to rendered
front page.

## How Generation Works

`POST /api/generate` (`src/app/api/generate/route.ts`) does the whole thing
in one request:

1. Resolve the period's date bounds (`src/lib/cadence.ts`).
2. Fetch the user's GitHub activity for that range
   (`src/lib/sources/github.ts`, using the server's `GITHUB_TOKEN`).
3. Resolve the visitor's chosen LLM provider + BYO key into a Mastra
   model config (`src/lib/ai/resolve.ts`) — never stored.
4. Run `periodPostWorkflow` (`src/mastra/workflows/period-post.ts`): an
   outline call plans the front page's sections from the fetched activity,
   then one call per section writes it (concurrency 1 — the point behind
   this is documented in the workflow file).
5. Map the result into the `IssueView`/`IssueArticle[]` shape the six
   `IssueV*` front-page layouts (`src/components/issue/`) already render.

The client (`src/components/AppClient.tsx`) shows a config form, a CSS-only
"generating" animation while the request is in flight, then the rendered
front page — all client-side state, no route change.

## Scripts

- `npm run dev` — development server.
- `npm run build` / `npm start` — production build and server.
- `npx tsc --noEmit` — typecheck (run `next build` or `next dev` at least once
  first; `.next/types` is generated by the build).
- `npx eslint .` — lint.

## Docker

Built and run via the repo-root `docker-compose.yml`.
